Certifique-se que tem python instalado na maquina.
Abra o CMD e execute o seguinte comando.
```bash
pyhton --version
```
Deve aparecer algo do tipo `Python 3.12.11 `. Caso não tenha instale o [python](!https://www.python.org/ftp/python/3.13.17/python-3.13.17-amd64.exe) na maquina sua maquina

Depois clique em main.bat para instalar as dependencias e rodar o codigo.
